# Holidaze

<img src="assets/images/Holidaze_logo_w.png" alt="Holidaze logo" width="200">

Holidaze is an accommodation booking application developed for Project Exam 2 at Noroff.

The application allows users to browse and search for venues, view availability and make bookings. Registered Venue Managers can create and manage their own venues and view bookings connected to them.

## Features

### All Users

- Browse available venues
- Search and filter venues
- View individual venue details
- View venue availability

### Registered Customers

- Register and log in
- Create bookings
- View upcoming bookings
- Update profile information

### Venue Managers

- Register and log in as a Venue Manager
- Create new venues
- Edit and delete owned venues
- View bookings for owned venues
- Manage profile information

## Getting Started

### Installing

Clone the repository:

```bash
git clone https://github.com/emmelinlarina/project-exam-2
```

Navigate to the project directory:

```bash
cd project-exam-2
```

Install the dependencies:

```bash
npm install
```

### Running the Project

Start Tailwind CSS in watch mode:

```bash
npm run dev
```

Then open the project using Live Server or another local development server.

### Production Build

To create a minified Tailwind CSS build:

```bash
npm run build
```
